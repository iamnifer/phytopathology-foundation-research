# Исходные шаблоны отчёта

В каталоге сохранены без смыслового редактирования файлы старого шаблона,
полученные 23 августа 2026 года:

- `title_kr_original.tex` — исходный титульный лист курсового проекта;
- `title_vkr_original.tex` — справочный титульный лист ВКР;
- `refs_original.bib` — прежняя версия библиографии.

Актуальный титульный лист находится в `../title_kr.tex`, а заполняемые поля —
в `../metadata.tex`. Его компоновка приведена в соответствие с
`title_kr_original.tex`; персональные данные из старого файла намеренно не
переносились, поскольку их актуальная версия ещё не подтверждена.

Актуальная библиография находится в `../refs.bib`: она содержит проверенные и
более полные записи, поэтому старый файл используется только как справочный.
