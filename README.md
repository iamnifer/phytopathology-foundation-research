# Сегментация заболеваний растений

Курсовая работа о переносе предобученных моделей на сегментацию поражений растений и о снижении объёма необходимой разметки. На [PlantSeg](https://github.com/tqwei05/PlantSeg) решается бинарная задача: поражение против фона. Сравниваются полностью дообучаемая DeepLabV3-ResNet50, DINOv3 ViT-B/16 с замороженным энкодером и SAM ViT-B без дообучения.

[Итоговый отчёт](report/coursework.pdf) · [Протоколы экспериментов](docs/README.md) · [Результаты в JSON](results/final_metrics.json) · [Дальнейшая работа](ROADMAP.md)

## Основные результаты

Главная метрика — IoU поражения по всему набору. Для повторённых экспериментов приведены среднее и стандартное отклонение по трём запускам.

| Сравнение | IoU поражения | Выборка |
|---|---:|---|
| DeepLabV3-ResNet50, полное дообучение | **0,6804 ± 0,0030** | тест |
| DINOv3 ViT-B/16, замороженный энкодер и свёрточный декодер | 0,6591 ± 0,0015 | тест |
| DINOv3 / ResNet-50 с одинаковым линейным декодером и замороженными энкодерами | **0,6108 / 0,3976** | тест |
| DINOv3, стратифицированные 25% обучающей выборки | 0,6243 ± 0,0028 | валидация |
| SAM ViT-B с точной рамкой из эталонной маски | 0,4659 | валидация |

В основном сравнении DeepLabV3 немного точнее, но в нём обучается вся сеть, а у DINOv3 — только декодер. При одинаковом линейном декодере замороженные признаки DINOv3 дают заметно более высокий результат. Четверть размеченных изображений обеспечивает около 95% качества обучения на полном наборе; более сложные способы отбора не дали устойчивого выигрыша над случайным. SAM получил подсказку из эталона, поэтому его результат **не** является качеством автоматической сегментации.

Подробности и отрицательные результаты приведены в [журнале экспериментов](docs/README.md). Ограничения итоговой тестовой оценки описаны в [эксперименте 023](docs/experiments/023_confirmatory_test_evaluation.md).

## Запуск

Нужен Python 3.10+; для полных экспериментов рекомендуется GPU. Установка и проверка:

~~~bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev,download]'
ruff check .
pytest -q
~~~

Скачайте [PlantSeg v3](https://github.com/tqwei05/PlantSeg) и разместите Metadatav2.csv, images/{train,val,test} и annotations/{train,val,test} в data/plantseg_v3/. Ожидаемые размеры: 7916 / 1247 / 2295 изображений. Проверьте данные командой `python -m phytopathology.audit_data data/plantseg_v3`.

Веса DINOv3 можно получить из ModelScope:

~~~bash
modelscope download --model facebook/dinov3-vitb16-pretrain-lvd1689m \
  --local_dir models/dinov3-vitb16-pretrain-lvd1689m
~~~

Проверочный запуск; для полного обучения уберите `--smoke-test`:

~~~bash
python -m phytopathology.train \
  --config configs/dinov3_vitb16_binary_multilayer_conv_cosine.yaml \
  --data-root data/plantseg_v3 --smoke-test
~~~

Сценарии для повторения основных сравнений указаны в [указателе экспериментов](docs/README.md). PDF отчёта собирается командой `./scripts/build_report.sh`; требования к LaTeX описаны в [report/README.md](report/README.md).

## Границы выводов

Работа посвящена бинарной маске поражения, а не распознаванию 115 заболеваний. Формальное название на титульном листе шире выполненной задачи: сегментация здесь рассматривается как классификация пикселей, а отдельные методы адаптации доменов остаются за рамками работы. Основное сравнение CNN и DINOv3 использует разные режимы дообучения; отдельный линейный эксперимент выравнивает их, но не устраняет различий в исходном предобучении. На ранней разведочной стадии часть тестовых результатов просматривалась, поэтому итоговый тест не следует считать полностью закрытым бенчмарком.

Использованы [PlantSeg](https://github.com/tqwei05/PlantSeg), [DINOv3](https://github.com/facebookresearch/dinov3), DeepLabV3 из torchvision и [SAM](https://github.com/facebookresearch/segment-anything). При планировании экспериментов также учитывалась [сходная открытая работа](https://github.com/dfbakin/plant-diseases-segmentation).
