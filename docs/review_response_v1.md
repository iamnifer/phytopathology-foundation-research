# План реакции на ревью v1

Дата: 2026-09-05. Исходное ревью хранится в рабочем каталоге как пользовательский
файл `Ревью курсовая Резниченко v1.md` и не изменяется.

## Пересмотренный результат курсовой

За оставшееся время работа должна дать не максимальное число разнородных
запусков, а воспроизводимое сравнение двух семейств моделей и проверенный вывод
об эффективности разметки:

1. сравнить CNN-бейзлайн и frozen DINOv3 при едином протоколе бинарной
   сегментации PlantSeg;
2. разложить прирост DINOv3 на decoder, schedule и multi-layer features, не
   приписывая статистическую значимость малому эффекту;
3. проверить, можно ли сохранить качество при разметке 10--25% изображений и
   превосходит ли representation-based selection сильный случайный baseline;
4. объяснить результаты через bootstrap-интервалы, примеры предсказаний,
   категории ошибок, размер поражения и анализ выбранных подмножеств;
5. сформулировать практические рекомендации с учётом времени обучения и
   инференса.

SAM остаётся диагностическим отрицательным результатом о vanilla
promptability. Его fine-tuning, DINO→SAM, uncertainty sampling, частичное
размораживание DINO и полный k-means grid не являются обещанными результатами
этой версии работы.

## Замечание → действие

| Замечание | Действие | Статус |
|---|---|---|
| Название обещает CNN | Обучить DeepLabV3-ResNet50 в том же split/resize/metric protocol; добавить pretrained и scratch control | в работе |
| Название обещает domain adaptation | Не заявлять отдельный DA-алгоритм; явно трактовать transfer learning как перенос ImageNet/DINO на PlantSeg и ограничить выводы | запланировано |
| Смешаны причины прироста 0.5944→0.6569 | Показывать отдельные decoder/schedule/multi-layer контроли и paired differences | частично готово |
| Test использован промежуточно | Честно описать ранние просмотры test и строить основные выводы по validation; новых просмотров до фиксации финала не делать | принято |
| n=3 мало для малых эффектов | Paired image bootstrap 10 000 итераций; multi-layer эффект назвать неопределённым | в работе |
| AULC по линейной оси и с общей точкой 100% | Пересчитать по log-budget, отдельно на диапазоне 1--25%, не включать общую 100% точку в сравнение методов | запланировано |
| Нет иллюстраций и таксономии ошибок | Добавить DINO/SAM панели, leakage-иллюстрацию prompts, выбранные random/farthest примеры и ручную разметку 50--100 ошибок | запланировано |
| Не проверено разрешение | Сравнить 384/512/768 при одинаковом DINO-рецепте и явно указать разрешение метрик | в работе |
| SAM-протокол неясен | Описать: ближайшая к центроиду foreground-точка, один box по объединению компонент, выбор маски по SAM predicted IoU | готово в коде, перенести в текст |
| Healthy false positives | В PlantSeg нет healthy rows; проверить внешний набор здоровых изображений, если он доступен без изменения основного протокола | опционально |
| Нет стоимости и рекомендаций | Сохранить train time, peak memory, inference throughput и итоговую таблицу рекомендаций | в работе |
| Терминология и литература | Русифицировать подписи; добавить первичные источники CNN/transformer/active learning/SAM | запланировано |

## Критерий готовности к 18 сентября

Обязательны: CNN baseline, resolution control, bootstrap для главных сравнений,
исправленный data-efficiency анализ, визуальные панели, честно суженные claims,
собирающийся PDF и проверка согласованности чисел. Внешний healthy-set тест
выполняется после обязательных пунктов. Fine-tuning SAM и новые большие ветки
не должны вытеснять эти проверки.
