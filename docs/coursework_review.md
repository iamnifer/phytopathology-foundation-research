# Аудит `coursework.tex`

Проверено: 2026-08-03. Исходный файл пока расположен уровнем выше Git-репозитория.

## Уже сделано

Текст задаёт предметную область, мотивирует pixel-level сегментацию, выбирает
DINOv3 и сравнивает PlantVillage с PlantSeg. Сформулированы направления
экспериментов: decoder heads, подбор обучения, анализ ошибок, SAM и few-shot
выборка по embeddings. Это хорошая основа для введения и постановки задачи.

## Блокирующие технические проблемы

- Документ сейчас не самодостаточен: отсутствуют `title_kr.tex`, `refs.bib` и
  каталог `graphics/`.
- Используются citation keys `dinov3`, `plantseg`, `plantvillage`, `sam3`, но
  библиография не приложена.
- `coursework.tex` находится вне Git и потому не будет сохранён вместе с кодом.
- В преамбуле `indentfirst` подключён дважды; есть неиспользуемые пакеты и
  большой закомментированный шаблон вместо фактических результатов.

## Содержательные пробелы

- Нет формальной постановки задачи: вход, целевая маска, 116 классов,
  train/val/test split и loss.
- Не определено, является ли главной задачей binary lesion/background
  segmentation или распознавание 115 видов болезни плюс фон. Цель `0.7 mIoU`
  реалистично трактуется совсем по-разному для этих двух протоколов.
- Нет определения mIoU и правила обработки отсутствующих классов/background.
- Нет раздела «Метод»: какие именно DINOv3-токены и слои используются, как
  устроен decoder, что заморожено.
- Нет экспериментального протокола, таблицы гиперпараметров, baseline-таблицы,
  оценок разброса и анализа ошибок.
- Few-shot пока назван целью, но не определены `K`, единица выборки, seeds и
  правило покрытия классов.
- mAP упомянут для semantic segmentation без определения. Для текущего
  multiclass semantic protocol основными метриками разумнее сделать mIoU,
  mAcc и per-class IoU; mAP оставить лишь при отдельной постановке instance
  segmentation/detection.
- «SAM в сыром виде» требует prompt protocol; без одинакового способа выдачи
  prompts сравнение с fully automatic semantic segmentation будет некорректно.

## Рекомендуемая структура итогового текста

1. Введение и формальная постановка задачи.
2. Обзор DINOv3, dense features, PlantSeg и методов адаптации.
3. Данные и протокол оценки.
4. Предлагаемый метод и варианты decoder head.
5. Эксперименты: baseline → ablations → few-shot → сравнение с SAM.
6. Анализ ошибок, ограничения и заключение.
