# Подтверждающая оценка зафиксированных моделей на PlantSeg test

Дата фиксации протокола: 14 сентября 2026 года, до расчёта новых test-метрик.

## Статус и назначение

Ранняя разведочная работа уже включала просмотр test для трёх промежуточных
конфигураций DINOv3. Поэтому эта серия не объявляется полностью независимой
оценкой. Она служит только подтверждающей проверкой двух уже сформулированных
по validation выводов. После просмотра результатов запрещены выбор другой
контрольной точки, настройка порога и изменение гиперпараметров.

## Проверяемые утверждения

1. В практически разных режимах переноса полностью дообученный
   DeepLabV3-ResNet50 и DINOv3 ViT-B/16 с замороженным энкодером дают близкое
   качество; малая разность может зависеть от сетки оценки.
2. При одинаковом минимальном линейном зондировании замороженные признаки
   DINOv3 существенно лучше признаков ResNet-50.

## Зафиксированные модели

Для каждого сравнения используются контрольные точки, ранее выбранные только
по validation, с начальными значениями генератора 42, 43 и 44.

- практическое сравнение: DINOv3 ViT-B/16, блоки 3/6/9/12 и свёрточный
  декодер против DeepLabV3-ResNet50 с ImageNet-инициализацией;
- согласованное сравнение признаков: замороженные DINOv3 ViT-B/16 и ResNet-50,
  одинаковая линейная голова и общая сетка признаков 24×24.

## Метрики и сетки

Для практического сравнения заранее считаются два представления одной и той же
test-оценки:

- сетка 384×384 — для прямого сопоставления с основной validation-таблицей;
- исходная сетка аннотации — для проверки чувствительности малой разности к
  дискретизации маски.

Для линейных зондов используется общая сетка оценки 384×384, совпадающая с
validation-протоколом. Везде фиксируются IoU поражения, mIoU двух классов,
Dice, точность, полнота и пиксельная AP. Разность IoU проверяется парным
бутстрепом по 2295 test-изображениям с 10 000 повторных выборок. Помимо
интервалов по изображениям приводятся среднее и выборочное стандартное
отклонение по трём запускам.

## Что намеренно не оценивается

Test не используется для сравнения разрешений, декодеров, числа слоёв,
порогов, методов отбора данных, SAM и контроля ResNet 48×48. Эти эксперименты
остаются validation-абляциями, чтобы подтверждающая серия не превратилась в
повторную настройку по test.

## Критерий вывода

Основной вывод считается воспроизведённым, если знак средней парной разности
совпадает с validation и результат не опирается на один запуск. Любое
расхождение будет сохранено как отрицательный результат без дополнительной
настройки моделей.
