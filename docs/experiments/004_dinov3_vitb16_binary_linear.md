# 004 — DINOv3 ViT-B/16 binary linear probe

## Задача

Проверить воспроизводимый baseline для сегментации `поражение / фон` более чем
за одну эпоху. Все исходные disease ids `1..115` отображаются в foreground `1`.

## Конфигурация

- Dataset: PlantSeg v3, официальный train/val split (`7916 / 1247`).
- Backbone: DINOv3 ViT-B/16, веса ModelScope, frozen.
- Decoder: `1x1 Conv`, то есть linear probe.
- Input: `384x384`, batch size 16, seed 42.
- Optimizer: AdamW, LR `1e-3`, weight decay `1e-4`.
- Epochs: 10, bfloat16 autocast.
- Run: `20260908T152130Z_dinov3_vitb16_binary_linear`.
- Commit запуска: `a6b540a6782f9884accc875a51ea8b6d4429a14d`.
- GPU: NVIDIA A100-SXM4-80GB; PyTorch `2.14.0+cu130`.

## Результат validation

Лучший checkpoint получен на эпохе 5:

| Метрика | Значение |
|---|---:|
| mean IoU, фон + поражение | 0.7391 |
| IoU фона | 0.8837 |
| IoU поражения | 0.5944 |
| Pixel accuracy | 0.9007 |
| Validation loss | 0.2279 |

На эпохе 1 mean IoU уже равен 0.7221, а на эпохах 6–10 устойчивого улучшения
нет. Поэтому цель 0.70 достижима, если под ней понимается среднее IoU двух
классов. Если целевая метрика — IoU самого поражения, текущий baseline даёт
0.5944 и требует улучшения.

## Результат test

| Метрика | Значение |
|---|---:|
| mean IoU, фон + поражение | 0.7431 |
| IoU поражения | 0.6036 |
| Dice поражения | 0.7528 |
| Precision поражения | 0.7871 |
| Recall поражения | 0.7214 |
| Pixel average precision | 0.8428 |

Отрисованы по три худших, медианных и лучших test-примера. Individual IoU в
выборке меняется от 0 до 0.9821. В худшем рассмотренном примере
`apple_black_rot_149.jpg` модель полностью пропустила размеченную область;
типичный пример показывает преимущественно false negatives внутри сложной
фрагментированной маски. Артефакты находятся на ВМ внутри каталога запуска в
`errors_test/` и не добавляются в Git.

Официальное описание PlantSeg называет эти маски `diseased parts`. Визуально
некоторые annotations покрывают почти весь лист или плод, поэтому в тексте
работы следует использовать формулировку «размеченная поражённая область», а
не обещать локализацию отдельных пятен для каждого изображения.
