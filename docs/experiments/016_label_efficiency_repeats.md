# Эффективность разметки: повторы при 10% и 25%

## Вопрос

Устойчиво ли стратифицированная выборка либо жадный отбор наиболее удалённых
примеров превосходят равномерный случайный отбор при практически значимых
бюджетах разметки?

## Протокол

Протокол совпадает с experiment 015: замороженный DINOv3 ViT-B/16,
многослойный свёрточный декодер, 384 px, одинаковое число шагов оптимизатора,
выбор контрольной точки только по валидационной выборке. Для бюджетов 10% и
25% выполнены запуски с начальными значениями генератора 42, 43 и 44. Тестовая
выборка не использовалась.

## Результаты

| Бюджет | Метод | Запуски IoU поражения | Среднее ± стандартное отклонение |
|---:|---|---|---:|
| 10% | случайный | 0.6047 / 0.5940 / 0.6062 | 0.6016 ± 0.0067 |
| 10% | стратифицированный | 0.6054 / 0.6004 / 0.6035 | 0.6031 ± 0.0025 |
| 10% | наиболее удалённые | 0.5906 / 0.5876 / 0.5790 | 0.5857 ± 0.0061 |
| 25% | случайный | 0.6244 / 0.6145 / 0.6266 | 0.6218 ± 0.0064 |
| 25% | стратифицированный | 0.6246 / 0.6214 / 0.6269 | 0.6243 ± 0.0028 |
| 25% | наиболее удалённые | 0.6179 / 0.6082 / 0.6102 | 0.6121 ± 0.0051 |

Парные разности по тем же трём начальным значениям:

| Бюджет | Сравнение | Средняя разность ± стандартное отклонение |
|---:|---|---:|
| 10% | стратифицированный − случайный | +0.0015 ± 0.0046 |
| 10% | наиболее удалённые − случайный | −0.0159 ± 0.0105 |
| 25% | стратифицированный − случайный | +0.0025 ± 0.0038 |
| 25% | наиболее удалённые − случайный | −0.0097 ± 0.0058 |

## Вывод

Стратификация по метаданным практически совпадает со случайным отбором: её
средний выигрыш меньше 0.003 и меньше межзапускового разброса. Жадный отбор
наиболее удалённых объектов во всех шести парных сравнениях хуже случайного,
но при трёх запусках численную величину эффекта следует считать
предварительной. Главный надёжный вывод серии — отсутствие преимущества
простого diversity-only отбора по глобально усреднённым DINO-признакам.

Утверждение «25% данных достаточно для 95% качества» также смягчается: порог
находится внутри межзапускового шума. Корректная формулировка — при 25% разметки
получено примерно 95% среднего качества полной выборки, а не гарантированное
достижение порога каждым методом.

## Артефакты

Полные истории и контрольные точки находятся на ВМ в каталогах
`runs/20260914T*_dinov3_vitb16_binary_multilayer_conv_cosine_*_seed4*_{0.1,0.25}`.
