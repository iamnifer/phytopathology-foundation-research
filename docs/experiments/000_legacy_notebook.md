Статус: exploratory, не воспроизведён.

## Что нельзя считать воспроизводимым результатом

1. В модели выставлено 115 выходов, тогда как официальный PlantSeg baseline
   использует 116 классов и не удаляет zero label.
2. IoU сначала считался отдельно для каждого изображения и каждого класса.
   Отсутствующий и в prediction, и в target класс давал 0, хотя должен быть
   исключён из среднего; правильнее сначала накопить confusion matrix по split.
3. Все 9163 preprocessing-тензора заранее загружались в RAM. В сохранённом
   выводе kernel падал при создании dataset; подход зависит от объёма памяти.
4. Визуализация применяет sigmoid к multiclass logits и порогует весь
   трёхмерный массив вместо `argmax` по классам.
5. Не сохранены seed, версии библиотек, checkpoint (в репозитории), время,
   commit и per-class metrics.
6. Использованный фактически датасет соответствует PlantSeg v3: split
   7916/1247/2295 и `Metadatav2.csv`. Официальный архив v2 имеет только
   train/test и содержит ошибочные test-имена масок в старой metadata.

## Ценность результата

Запуск подтверждает жизнеспособность frozen dense features DINOv3 и задаёт
ориентир порядка 0.45 mIoU. После проверки корректной разметки его нужно
повторить через CLI и только тогда использовать в сравнительной таблице.
