# Исследовательская программа

Обновлено 2026-09-16 после ревью руководителя и завершения повторов
экспериментов по эффективности разметки.

## Цель

Исследовать компромисс между качеством и объёмом пиксельной разметки при
переносе CNN и трансформерных/фундаментальных моделей на бинарную сегментацию
поражённых областей растений на PlantSeg.

Итог работы должен отвечать не на вопрос «какой запуск дал самое большое
число», а на три проверяемых исследовательских вопроса:

1. Какие части адаптации DINOv3 дают устойчивый прирост и как меняют качество
   малых поражений?
2. Как базовая CNN соотносится с замороженным DINOv3 и как качество зависит от
   разрешения входа и размера поражения?
3. Какие изображения следует размечать первыми и сколько размеченных
   изображений нужно, чтобы приблизиться к качеству на полной выборке?

## Единый протокол

- Задача: поражение (`all source labels > 0`) против фона (`0`),
  `ignore_index=255` не участвует в метриках.
- Единица бюджета разметки: полностью размеченное изображение. Выбор отдельных
  областей остаётся возможным расширением, но не смешивается с основной кривой.
- Главная метрика: агрегированное по валидации IoU поражения.
- Дополнительные метрики: среднее IoU фона и поражения, Dice, точность,
  полнота, пиксельная AP, среднее IoU по изображениям и IoU по квартилям
  площади поражения.
- Контрольная точка, порог и гиперпараметры выбираются только по валидации.
  Тест был просмотрен в ранней разведочной серии, поэтому не используется для
  текущего выбора моделей; основные выводы строятся по валидации.
- Ключевые результаты: минимум три начальных значения генератора, среднее и
  выборочное стандартное отклонение. Отрицательные результаты
  сохраняются наравне с положительными.
- Для экспериментов с бюджетом данных фиксируются число шагов оптимизатора и
  правило выбора контрольной точки: малые подмножества не должны получать
  меньше обновлений только из-за меньшего числа изображений.

## Линия A — качество адаптации

### A1. Причинная абляция DINOv3

Изначально лучший результат смешивал многослойные признаки и 30-эпоховое
косинусное расписание. Для разделения эффектов выполнены:

1. ~~повторы многослойного декодера для значений 43 и 44~~ — выполнено, итог
   по трём запускам: $0.6519\pm0.0062$ IoU поражения;
2. ~~однослойный свёрточный декодер с тем же 30-эпоховым косинусным
   расписанием~~ — выполнено: $0.6444\pm0.0007$ против $0.6519\pm0.0062$ у
   многослойного;
3. ~~один метод с учётом площади поражения~~ — увеличение веса целых
   изображений дало отрицательный результат; возможное продолжение только в
   виде выбора фрагментов или функции потерь с учётом поражения.

Частичное размораживание последних блоков ViT и перенос финального рецепта на
ViT-L/16 отложены: они не должны вытеснять CNN-сравнение, контроль разрешения,
бутстреп и анализ ошибок до срока текущего отчёта.

Нельзя интерпретировать ViT-B против ViT-L как полное сравнение размеров: пока
они сопоставлены только с линейным декодером.

### A2. SAM

Для SAM различаются три режима, но в текущий обязательный результат входит
только первый:

1. качество по подсказкам из эталона: положительная точка и рамка выполнены;
   получено 0.3624 и 0.4659 IoU поражения. Это верхняя диагностическая оценка, а
   не автоматическая сегментация.
2. автоматическое уточнение: рамка или точки извлекаются из грубой маски DINOv3
   без истинной разметки — дальнейшая работа;
3. адаптация: обучение декодера масок, затем при необходимости LoRA/адаптер
   энкодера изображения — дальнейшая работа.

Автоматический генератор масок SAM без семантического правила выбора не
считается решением сегментации заболевания.

## Линия B — эффективность разметки

Замороженный DINOv3 вычисляет признаки фрагментов всего обучающего набора. Для
основной серии они агрегируются в $L_2$-нормированный дескриптор изображения;
выбранные индексы сохраняются до обучения.

### Методы холодного старта

1. равномерный случайный отбор — обязательная точка отсчёта;
2. стратифицированный случайный отбор по доступной метке заболевания —
   отдельная сильная точка отсчёта, использующая метаданные;
3. представители $k$-means либо $k$-medoids — типичные объекты;
4. жадный отбор наиболее удалённых объектов — разнообразие и покрытие
   пространства признаков.

### Последовательный метод (дальнейшая работа)

После небольшого начального набора обучается модель. Для оставшегося множества
считается попиксельная неопределённость, после чего выбираются неопределённые,
но не дублирующие друг друга изображения. Этот гибрид неопределённости и
разнообразия остаётся расширением исследования после текущего отчёта.

### Бюджеты и итоговые величины

Основная сетка: 1, 5, 10, 25, 50 и 100% обучения. Если 1% оказывается слишком
нестабильным, он остаётся диагностической точкой, а статистические выводы
начинаются с 5%.

Для каждого метода строятся:

- валидационное IoU поражения против числа размеченных изображений;
- нормированная площадь под кривой обучения;
- минимальная доля данных, достигающая 95% IoU модели на полной выборке;
- стоимость самого отбора и распределение выбранных примеров по заболеванию и
  площади поражения (последнее используется только для анализа, не для
  неуправляемого выбора).

## Что должно оказаться в финале

Минимально достаточный содержательный финал:

1. собственная базовая модель DeepLabV3-ResNet50 и DINOv3 при едином протоколе;
2. контролируемая абляция декодера, расписания и многослойных признаков DINOv3
   с бутстрепом;
3. кривые эффективности разметки для случайного и основанного на признаках
   отбора;
4. контроль 384/512/768 px, анализ малых поражений и типичных ложных
   срабатываний/пропусков;
5. качество SAM по подсказкам как отдельная диагностическая проверка без
   заявления о полностью автоматической сегментации заболевания;
6. выводы в форме рекомендаций с вычислительной стоимостью.

Успех не определяется заранее числом 0.70. Весомым является и отрицательный
результат, если протокол показывает, например, что SAM не исправляет грубые
маски или кластеризация DINOv3 не превосходит случайный отбор. Числовые
ориентиры нужны для проверки правдоподобия, но не для подгонки экспериментов.

## Порядок выполнения до финального отчёта

1. CNN с ImageNet-весами/случайной инициализацией и контроль DINO 384/512/768.
2. Парный бутстреп по изображениям и анализ эффективности разметки по
   логарифму бюджета.
3. Визуализации, ручная таксономия ошибок, время/память/инференс.
4. Переписывание отчёта и только затем один зафиксированный финальный тест,
   если протокол ещё допускает содержательно честную оценку.

Дообучение SAM, автоматический DINO→SAM, отбор по неопределённости, частичное
размораживание и расширенная кластеризация сохраняются как дальнейшая работа.
Они не являются условием завершения текущей курсовой.
