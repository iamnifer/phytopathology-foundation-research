# Ноутбуки

Ноутбуки используются для визуализации и анализа уже сохранённых результатов.
Обучение и оценка должны запускаться через `python -m phytopathology.train`,
чтобы конфигурация и метрики не терялись.

Исходный ноутбук сохранён без содержательных изменений как
`archive/legacy_dinov3_experiment.ipynb`. Это исторический артефакт первого
запуска, а не актуальная точка входа для обучения.
