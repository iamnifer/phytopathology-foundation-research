# Сводные результаты

В файле [final_metrics.json](final_metrics.json) собраны основные численные
результаты курсовой работы в машиночитаемом виде. Подробности о контрольных
точках, протоколах, бутстреп-интервалах и ограничениях приведены в
[журнале экспериментов](../docs/README.md).

Большие контрольные точки, предсказания для отдельных изображений и полные
журналы обучения в Git не хранятся. Производные результаты сохранены в отчёте
и протоколах экспериментов.
